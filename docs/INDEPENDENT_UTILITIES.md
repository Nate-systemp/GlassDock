# Independent utilities and Wi-Fi

The separately requested utility follow-up adds Settings → Add Utilities. Nothing is selected by default. Wi-Fi can be added or removed; the other seven catalog entries are explicitly unavailable. Selections are normalized, deduplicated and persisted by the existing settings store. Settings and utilities share an independent Light/Dark preference; main dock material presets remain intact.

## Ownership

- Core: `UtilitySettings` owns the catalog, colors and selection normalization; `UtilityPlacement` positions circles beside the current dock rectangle; `UtilitySvg` recolors existing SVG assets; `WifiProfile` validates and serializes personal/open WLAN profiles.
- Windows: `WifiUtilityService` observes actual radio state and toggles radios. `WifiNetworkControl` scans with WLAN notifications, deduplicates networks, submits native connections and waits for connected-state confirmation. No Doky credential storage or logging is added. Auto-connect profiles are stored by Windows; manual new connections use temporary profiles. Enterprise and unsupported security setup is delegated to Windows Settings.
- App: `SettingsWindow.Utilities` manages selection. `DesktopOverlayWindow.Utilities` owns a separate canvas, independent buttons and the Wi-Fi flyout. Utilities do not enter the application collection. `UtilityGlassSurface` uses the dock's existing capture and shader, with one circular drawing target per button and no extra capture session.
- Shared runtime owns one Wi-Fi service across monitor windows. Closing a flyout cancels its work; dock shutdown disposes utility resources before the shared renderer.

Selected circles follow the expanded dock's row, visibility and transition opacity, with a 12-DIP scaled gap. Their diameter follows the dock's actual visible height, including animated sizing and bottom-attached clipping, with equal width and height. They hide with the collapsed dock and fullscreen suppression. Dock width is capped only when needed to reserve room on the right. Application drag/reorder behavior remains separate; pointer movement over utilities resets app magnification and the dock wave.
