# Doky application icons

`doky-logo.png` is the master artwork. Run `scripts/Generate-DokyIcons.ps1`
from the repository to regenerate `src/GlassDock.App/Assets/Doky.ico` and
`Doky.png`. Each size is resampled directly from the master with transparent
padding and unchanged proportions, never from another smaller frame.

The ICO contains 32-bit alpha PNG frames at 16, 20, 24, 32, 40, 48, 64, 96,
128 and 256 pixels. The 256-pixel PNG is used in Settings/About. The ICO is
embedded in both executables and assigned to WinUI windows, including the
laboratory and development controls. Existing shortcuts inherit the executable
icon; WiX also explicitly uses it for the Start Menu and installed-product icon.
The legacy Inno script uses it for Setup and inherits executable shortcut icons.

For future Velopack packaging, include:

```powershell
--icon .\src\GlassDock.App\Assets\Doky.ico
```

Keep the existing package ID, version arguments, main executable and other
packaging options. This sets Velopack's installer/package icon; its shortcuts
target the branded executable. No release is generated by the asset script.
Existing installed shortcuts or Explorer may retain cached icons until the next
installation/refresh; this source change does not replace previously built packages.
